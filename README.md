# РабКаб — обновления

Публичный канал для установщиков и автоматических обновлений приложения РабКаб.

Исходный код приложения находится в отдельном приватном репозитории. Этот репозиторий содержит только готовые бинарные сборки и файл-манифест, который приложение использует для проверки новых версий.

## Установка

Скачайте `RabKabSetup-<версия>.exe` со страницы [Releases](https://github.com/lazydq33/RabKab-Updates/releases).

## Автоматические обновления

Приложение проверяет файл `update.json` в основной ветке этого репозитория. Если доступна версия новее установленной, РабКаб предложит скачать и установить ее. Перед запуском загруженного апдейтера приложение проверяет SHA-256 файла.

Публикуются только установщики и обновляющий пакет. Не размещайте здесь исходный код или рабочие данные пользователей.
